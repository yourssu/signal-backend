# 경량 하네스 초기화

새 프로젝트 또는 기존 하네스 업데이트 요청에 사용한다.

1. 언어, 빌드 도구, 테스트, CI, 에이전트 지침과 ignore 상태를 읽는다.
2. Git 공유 변경이면 먼저 Issue를 생성하고 별도 브랜치 또는 worktree를 사용한다.
3. `.agents`를 공용 SSOT로 만들고 `.claude`, `.codex`는 로컬 어댑터로 제외한다.
4. 공용 템플릿은 `.agents/harness.yml`, `workflows`, 필요한 skills와 hooks만 설치한다.
5. 프로젝트 고유 명령은 `.agents/project.yml`에 기록한다.
6. 기존 파일을 덮어쓰기 전에 diff를 보여주고 프로젝트 고유 규칙을 보존한다.
7. 심볼릭 링크와 절대 경로를 만들지 않는다.
8. 초기화 스크립트와 프로젝트 검증을 실행하고 PR 생성까지만 수행한다.

전역 설치본은 부트스트랩 역할만 한다. 초기화 이후에는 각 저장소의 `.agents`가 해당 프로젝트의 원본이다.
