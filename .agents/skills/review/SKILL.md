# 독립 리뷰

리뷰어는 구현자의 결론을 전제로 삼지 않는다. Issue, `.agents/local/specs`, base 대비 diff, 테스트 결과와 실제 동작 증거만 확인한다.

우선순위:

- P1: 배포·기동 실패, 데이터 손실, 보안 침해, 핵심 기능 중단
- P2: 현실적인 회귀, 알림 유실, 호환성 위반, 정상 흐름의 오판
- P3: 제한적인 유지보수 문제

각 지적에는 재현 조건, 영향, 정확한 파일·행과 최소 수정 방향을 포함한다. 스타일 선호, 범위 밖 리팩토링, 근거 없는 가능성은 차단 지적으로 만들지 않는다.

- Small: 구현자 자체 diff 검토
- Medium: 독립 리뷰어 1명
- Large: 코드·회귀와 보안·운영 리뷰를 분리

P1·P2는 수정 후 같은 관점으로 재검토한다.
