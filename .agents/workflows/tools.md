# 개발 도구 정책

## 선택 기준

- 저장소·빌드·Git·Docker는 재현 가능한 로컬 CLI를 우선한다.
- Chrome DevTools MCP는 개발 중 실제 브라우저 조작, 콘솔, 네트워크, Lighthouse 진단에 사용한다.
- 반복해야 하는 브라우저 회귀는 프로젝트에 Playwright 테스트 코드로 저장하고 CLI·CI에서 실행한다.
- 같은 기능을 제공하는 MCP를 중복 연결하지 않는다.

## 외부 서비스

- Figma 공식 MCP: 링크가 지정된 파일·노드 읽기, 요청된 디자인 생성·수정
- Notion 공식 MCP: 사용자가 접근 가능한 문서·DB 읽기, 요청된 페이지·DB 생성·수정
- GitHub: `gh` CLI 사용

Figma·Notion 읽기는 작업 분석에 필요한 범위에서 진행할 수 있다. 쓰기는 사용자가 요청한 대상과 범위 안에서만 수행하고 결과를 보고한다. 삭제, 공개 범위 변경, 권한 변경과 대량 수정은 별도 승인을 받는다. OAuth 토큰과 계정 정보는 저장소에 기록하지 않는다.

## 브라우저 검증 증거

- 사용한 URL과 환경
- 실행한 사용자 시나리오
- 핵심 요청의 method, path, status
- 콘솔 오류 유무
- 성공·실패 화면 또는 응답의 관찰 결과

로그인 토큰, 쿠키, 연락처와 시크릿은 증거에 포함하지 않는다.
